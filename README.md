# Clara challenge — Growth Orchestration System

This repository and its Netlify site (https://clara-growth-agent-demo.netlify.app) are dedicated to the Clara
**Growth Orchestration System** challenge:

```
event → state → decision → AI/rules → action → audit
```

- **Everything is in [`growth-orchestrator/`](growth-orchestrator/README.md)**: the system, the synthetic data
  (50,000 accounts generated by code), tests, AI evals and docs.
- **Web page**: `public/index.html` (data in `public/data/`, regenerated with `python3 -m orchestrator export-web`).
- **Live AI function**: `netlify/functions/orchestrator-llm.mjs` (key server-side, no email code).
- All data is synthetic and **no email is ever sent**: outreach goes to a mock ledger.
